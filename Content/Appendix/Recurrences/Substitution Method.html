Substitution Method

Substitution Method

The substitution method might be better called the guess and prove it by induction method. To use it, we first guess a closed form for the recurrence, and then we prove that the guess is correct. Because recurrence relations define each value in terms of earlier values, induction is a natural way to prove that a proposed solution works.

In practice, the substitution method usually has three steps:

  1. Compute a few values or otherwise guess a closed form.
  2. Check that the formula agrees with the base case or base cases.
  3. Use the recurrence relation to prove the guessed formula by induction.

Example 1

Consider the recurrence

\[ S(n) = \left\{ \begin{array}{ll} 1&\mbox{when n = 1}\\ S(n-1) + n & \mbox{otherwise} \end{array} \right. \]

Prove that the solution is \({\displaystyle S(n)=\frac{n(n+1)}{2}.}\)

Proof

When \(n=1\), \(S(1)=1 = \frac{1(1+1)}{2}\). Assume that \(S(k-1)=\frac{(k-1)k}{2}\). Then

\[ \begin{aligned} S(k)&=S(k-1)+k\, \qquad \quad \mbox{(Definition of }S(k)\mbox{)}\\ &=\dfrac{(k-1)(k)}{2}+k\,\qquad \mbox{(Inductive hypothesis)}\\ &=\dfrac{k^2-k}{2}+k\, \qquad \qquad \mbox{(The rest is just algebra)}\\ &=\dfrac{k^2-k+2 k}{2}\\ &=\dfrac{k^2+k}{2}\\ &=\dfrac{k(k+1)}{2}. \end{aligned} \]

By PMI, \(S(n)=\frac{n(n+1)}{2}\) for all \(n\geq 1\).

Exercise 1

Recall that earlier we developed the recurrence relation \(T(n)=T(n/2)+1\) for the complexity of binarySearch. For this exercise, assume \(n\) is a power of 2 and use \(T(1)=1\) as the base case. Use substitution to prove that \(T(n)=\log_2 n+1\) is a solution to this recurrence relation.

When \(n=1\), \(T(1)=1=0+1=\log_2 1 + 1\). Assume that \(T(k)=\log_2 k + 1\) for all \(1\leq k <n\) (we are using strong induction). Then

\[ \begin{aligned} T(n)&=T(n/2)+1\\ &=(\log_2 (n/2) + 1) + 1\\ &=\log_2 n - \log_2 2 + 2\\ &=\log_2 n - 1 + 2\\ &=\log_2 n +1. \end{aligned} \]

So by induction, \(T(n)=\log_2 n+1\) for all powers of 2 with \(n\geq 1\).

Example 2

Solve the recurrence

\[ H_n = \left\{ \begin{array}{ll} 1&\mbox{when n = 1}\\ 2 H_{n-1} + 1 & \mbox{otherwise} \end{array} \right. \]

Proof

Notice that \(H_1=1\), \(H_2=2\cdot 1 + 1 = 3\), \(H_3=2\cdot 3+1 = 7\), and \(H_4=2\cdot 7 + 1=15\). It sure looks like \(H_n=2^n-1\), but now we need to prove it. Since \(H_1=1=2^1-1\), we have our base case of \(n=1\). Assume \(H_n=2^n-1\). Then

\[ \begin{aligned} H_{n+1}&=2H_n+1\\ &=2(2^n-1)+1\\ &=2^{n+1}-1, \end{aligned} \]

and the result follows by induction.

Exercise 2

Find a closed form for the following recurrence relation and use induction to prove your solution is correct: \(A(n)=A(n-1)+2\), \(A(1)=2\).

We begin by computing a few values to look for a pattern:

\[ \begin{aligned} A(1) &= 2,\\ A(2) &= A(1)+2 = 2+2 = 4,\\ A(3) &= A(2)+2 = 4+2 = 6,\\ A(4) &= 8,\\ A(5) &= 10. \end{aligned} \]

These values suggest that \(A(n)=2n\). We now prove this formula by induction.

The formula holds when \(n=1\), since \(A(1)=2=2\cdot 1\). Now assume \(A(n)=2n\) for some \(n\geq 1\). Then

\[ A(n+1)=A(n)+2=2n+2=2(n+1). \]

Therefore, if the formula holds for \(n\), it also holds for \(n+1\). By induction, \(A(n)=2n\) for all \(n\geq 1\).

Example 3

Why is the straightforward recursive algorithm for computing \(f_n\) given below so inefficient?

int FibR(int n) {
  if (n == 0 || n == 1) {
    return n;
  } else {
    return FibR(n - 1) + FibR(n - 2);
  }
}

Solution

Let's count the number of additions FibR(n) performs, since addition is the main nonrecursive operation in the algorithm.

Let \(F(n)\) be the number of additions required to compute \(f_n\) using FibR(n). If \(n=0\) or \(n=1\), the algorithm returns immediately and performs no additions, so \(F(0)=F(1)=0\). If \(n\geq 2\), the algorithm calls FibR(n - 1) and FibR(n - 2), then adds the two returned values. Therefore,

\[ F(n)=F(n-1)+F(n-2)+1. \]

We could solve this using a general technique for linear recurrences, but the algebra is more than we need here. Instead, let's compute some values and look for a pattern.

\[ \begin{aligned} F(0)&=0\\ F(1)&=0\\ F(2)&=F(1)+F(0)+1 = 1\\ F(3)&=F(2)+F(1)+1 = 2\\ F(4)&=F(3)+F(2)+1 = 4\\ F(5)&=F(4)+F(3)+1 = 7\\ F(6)&=F(5)+F(4)+1 = 12\\ F(7)&=F(6)+F(5)+1 = 20 \end{aligned} \]

The pattern is easier to see if we add 1 to each value:

\[ 1,\;1,\;2,\;3,\;5,\;8,\;13,\;21,\ldots \]

This is the Fibonacci sequence. More precisely, it suggests that

\[ F(n)=f_{n+1}-1. \]

We prove this by strong induction. First,

\[ F(0)=0=f_1-1 \qquad\text{and}\qquad F(1)=0=f_2-1. \]

Now assume the formula holds for all values less than \(k\), where \(k\geq 2\). Then

\[ \begin{aligned} F(k)&=F(k-1)+F(k-2)+1\\ &=(f_k-1)+(f_{k-1}-1)+1\\ &=f_k+f_{k-1}-1\\ &=f_{k+1}-1. \end{aligned} \]

Therefore, by strong induction, \(F(n)=f_{n+1}-1\) for all \(n\geq 0\).

So FibR(n) performs \(f_{n+1}-1\) additions just to compute \(f_n\). In a sense, the algorithm computes \(f_n\) by repeatedly adding together many copies of the base-case values \(0\) and \(1\). Since Fibonacci numbers grow exponentially, the number of additions also grows exponentially. The inefficiency comes from recomputing the same smaller Fibonacci values many times.

Reading Comprehension Questions

  1. Substitution Method: Why might the substitution method also be called the "guess and prove it by induction" method?
  2. Base Cases: Why is it important to check the base case before proving the inductive step?
  3. Guessing a Formula: In Example 2, how did computing the first few values help suggest the formula \(H_n=2^n-1\)?
  4. Binary Search: Why does the recurrence \(T(n)=T(n/2)+1\) lead naturally to a logarithmic solution?
  5. Recursive Fibonacci: What causes the straightforward recursive Fibonacci algorithm to be inefficient?
  1. Answer: The substitution method begins by guessing a closed form for the recurrence and then proving that the guess is correct, usually by induction.
  2. Answer: The base case anchors the induction proof. Without it, the inductive step only shows that one case follows from a previous case, but it does not show that the chain of implications ever starts.
  3. Answer: The first few values are \(1,3,7,15,\ldots\), which are one less than powers of 2: \(2^1-1,2^2-1,2^3-1,2^4-1,\ldots\). This suggests \(H_n=2^n-1\).
  4. Answer: Each recursive call cuts the input size in half. The number of times \(n\) can be divided by 2 before reaching 1 is \(\log_2 n\), so the solution has logarithmic growth.
  5. Answer: The algorithm recomputes the same smaller Fibonacci values many times. This causes the number of additions, and therefore the running time, to grow exponentially.

In-Class Activities

  1. Guess and Check: For the recurrence \(A(n)=A(n-1)+3\), \(A(1)=3\), compute \(A(1)\) through \(A(5)\). Guess a closed form, then prove it by induction.
  2. Find the Error: A student claims that \(H_n=2^n\) solves \(H_1=1\), \(H_n=2H_{n-1}+1\). Check the base case and the recurrence, and explain exactly where the proposed solution fails.
  3. Find and Prove a Closed Form: Consider the recurrence \[ A(n)=A(n-1)+2n-1,\qquad A(1)=1. \]
    1. Compute \(A(1)\), \(A(2)\), \(A(3)\), \(A(4)\), and \(A(5)\).
    2. Use those values to guess a closed form for \(A(n)\).
    3. Prove your formula by induction.
  4. Prove a Given Formula: Consider the recurrence \[ B(n)=2B(n-1)+n,\qquad B(1)=1. \] The closed form is \[ B(n)=4\cdot 2^{n-1}-n-2. \]
    1. Verify the formula for \(n=1\), \(n=2\), and \(n=3\).
    2. Prove the formula by induction.
  5. Fibonacci Repetition: Draw the recursive calls made by FibR(5). Count how many times FibR(3), FibR(2), FibR(1), and FibR(0) appear. Use the diagram to explain why repeated work is the source of the inefficiency.

Homework Problems

  1. Quadratic Recurrence: Find a closed form for \[ A(n)=A(n-1)+2n,\qquad A(1)=2, \] and prove your formula by induction.
  2. Geometric Recurrence: Find a closed form for \[ B(n)=3B(n-1),\qquad B(1)=3, \] and prove your formula by induction.
  3. A Slightly Different Sum Recurrence: Find a closed form for \[ C(n)=C(n-1)+2n,\qquad C(1)=2, \] and prove your formula by induction.
  4. One-Branch Halving Recurrence: Assume \(n\) is a power of 2. Find a closed form for \[ T(n)=T(n/2)+2,\qquad T(1)=1, \] and prove your formula by induction. (Hint: This is similar to the binary search recurrence, and the solution is similar. Compute a few values and look for a pattern.)
  5. Two-Branch Halving Recurrence: Assume \(n\) is a power of 2. Find a closed form for \[ T(n)=2T(n/2)+2,\qquad T(1)=1, \] and prove your formula by induction. (Hint: The solution is of the form \(T(n)=an+b\). Compute a few values and look for a pattern.)
  6. Modified Exponential Recurrence: Find a closed form for \[ H(n)=2H(n-1)+3,\qquad H(1)=1, \] and prove your formula by induction.
  7. Recursive Calls in Fibonacci: The example in this section counted the number of additions performed by FibR(n). In this problem, we will instead count the total number of calls to FibR, including the original call. This is another way to measure the running time, since each call performs only constant work besides its recursive calls.
    1. Let \(C(n)\) be the total number of calls made while computing FibR(n), including the original call. Give a recurrence relation for \(C(n)\), including base cases.
    2. Compute \(C(0)\), \(C(1)\), \(C(2)\), \(C(3)\), \(C(4)\), \(C(5)\), and \(C(6)\).
    3. Use your values to guess a closed form for \(C(n)\) in terms of Fibonacci numbers.
    4. Prove your formula by strong induction.
    5. Explain why this supports the claim that the straightforward recursive Fibonacci algorithm is inefficient.
  8. Closed Form for Fibonacci Numbers: Let \(F_0=0\), \(F_1=1\), and \[ F_n=F_{n-1}+F_{n-2} \] for \(n\geq 2\). Define \[ \phi=\frac{1+\sqrt{5}}{2} \qquad\text{and}\qquad \psi=\frac{1-\sqrt{5}}{2}. \] Prove by induction that \[ F_n=\frac{\phi^n-\psi^n}{\sqrt{5}} \] for all \(n\geq 0\).
    1. Verify the formula for \(n=0\) and \(n=1\).
    2. Show that both \(\phi\) and \(\psi\) satisfy \[ x^2=x+1. \]
    3. Use the identity \(x^2=x+1\) to explain why \[ x^n=x^{n-1}+x^{n-2} \] for \(x=\phi\) or \(x=\psi\), when \(n\geq 2\).
    4. Use strong induction to prove the closed form. You will use the fact that both \(\phi\) and \(\psi\) satisfy \(x^2=x+1\).
