Iteration Method

Iteration Method

With the iteration method (sometimes called backward substitution), we expand the recurrence and express it as a summation dependent only on \(n\) and initial conditions. Then we evaluate the summation. Sometimes the closed form of the sum is obvious as we are iterating (so no actual summation appears in our work), while at other times it is not (in which case we do end up with an actual summation).

Our first example perhaps has too many steps of algebra, but it never hurts to be extra careful when doing so much algebra. We also don't provide a whole lot of justification or explanation for the steps. We will do that in the next example. It is easier to see the overall idea of the iteration method if we don't interrupt it with comments. If this example does not make sense, come back to it after reading the next example.

Example 1

Solve the recurrence

\[ R(n) = \left\{ \begin{array}{ll} 1&\mbox{when n = 1}\\ 2 R(n/2) + n/2 & \mbox{otherwise} \end{array} \right. \]

Proof

To solve this recurrence relation with the iteration method, we will repeatedly substitute the definition into itself until we recognize a pattern, get to the base case, and do some algebra.

In the colored lines below, the blue term is the recursive call being replaced. The orange expression is the result of applying the recurrence to that term.

\[ \begin{aligned} R(n)&=2{\color{#0066cc}{R(n/2)}} + n/2\\ &=2{\color{#cc5500}{\left(2 R(n/4) + n/4\right)}} + n/2\\ &=2^2R(n/4) + n/2+n/2\\ &= 2^2{\color{#0066cc}{R(n/4)}} + n\\ &=2^2{\color{#cc5500}{\left(2 R(n/8) + n/8\right)}} + n\\ &=2^3R(n/8) + n/2+n\\ &=2^3{\color{#0066cc}{R(n/8)}} + 3n/2\\ &=2^3{\color{#cc5500}{\left(2 R(n/16) + n/16\right)}} + 3n/2\\ &=2^4R(n/16) + n/2 + 3n/2\\ &=2^4R(n/16) + 2n\\ &\vdots\\ &=2^k R(n/(2^k)) + k n/2\\ &=2^{\log_2 n} R(n/(2^{\log_2 n})) + (\log_2 n) n/2\\ &=n R(n/n) + (\log_2 n) n/2\\ &=n R(1) + (\log_2 n) n/2\\ &=n + (\log_2 n) n/2 \end{aligned} \]

Using this method requires a little abstract thinking and pattern recognition. It also requires good algebra skills. Care must be taken when doing algebra, especially with the non-recursive terms. Sometimes you should combine them immediately, and other times you should leave them expanded so the pattern remains visible. The problem is that it takes experience (i.e. practice) to determine which one is better in a given situation. The key is flexibility. If you try doing it one way and don't see a pattern, try another way.

Here is my suggestion for using this method

  1. Iterate enough times so you are certain of what the pattern is. Typically this means at least 3 or 4 iterations.
  2. As you iterate, make adjustments to your algebra as necessary so you can see the pattern. For instance, whether you write \(2^3\) or \(8\) can make a difference in seeing the pattern.
  3. Once you see the pattern, generalize it, writing what it should look like after \(k\) iterations.
  4. Determine the value of \(k\) that will get you to the base case, and then plug it in.
  5. Simplify.

Question 1

The iteration method is probably not a good choice to solve the following recurrence relation. Explain why.

\[ T(n)=T(n-1)+3T(n-2)+n\cdot T(n/3)+n^2,\, \, \, T(1)=17 \]

It contains 3 very different looking recursive terms so it is very unlikely we will be able to find any sort of meaningful pattern by iteration.

Here is an example that contains more of an explanation of the technique.

Example 2

Solve the recurrence relation \(T(n)=2T(n/2)+ n^3\), \(T(1)=1\).

Solution

We start by backward substitution:

\[ \begin{aligned} T(n)&=2{\color{#0066cc}{T(n/2)}}+n^3\\ &=2{\color{#cc5500}{\left[2T(n/4)+(n/2)^3\right]}}+n^3\\ &=2\left[2T(n/4)+n^3/8\right]+n^3\\ &=2^2T(n/4)+n^3/4+n^3 \end{aligned} \]

Notice that in the second line we have \((n/2)^3\) and not \(n^3\). This may be more clear if we rewrite the formula using \(k\): \(T(k)=2T(k/2)+k^3\). When applying the formula to \(T(n/2)\), we have \(k=n/2\), so we get

\[ {\color{#0066cc}{T(n/2)}}= {\color{#cc5500}{2T((n/2)/2)+(n/2)^3}} =2T(n/4)+n^3/8. \]

Back to the second line, also notice that the \(2\) is multiplied by both the \(2T(n/4)\) and the \((n/2)^3\) terms. A common error is to lose one of the \(2\)s on the \(T(n/4)\) term or miss it on the \((n/2)^3\) term when simplifying. Also, \((n/2)^3=n^3/8\), not \(n^3/2\). This is another common mistake. Continuing,

\[ \begin{aligned} T(n)&=\ldots\\ &=2^2{\color{#0066cc}{T(n/4)}}+n^3/4+n^3\\ &=2^2{\color{#cc5500}{\left[2T(n/8)+(n/4)^3\right]}}+n^3/4+n^3\\ &=2^2\left[2T(n/8)+n^3/4^3\right]+n^3/4+n^3\\ &=2^3T(n/8)+n^3/4^2+n^3/4+n^3. \end{aligned} \]

By now you should have noticed that I use 2 or more steps for every iteration--I do one substitution and then simplify it before moving on to the next substitution. This helps to ensure I don't make algebra mistakes and that I can write it out in a way that helps me see a pattern.

Next, notice that we can write the last line as

\[ 2^3T(n/2^3)+n^3/4^2+n^3/4^1+n^3/4^0, \]

so it appears that we can generalize this to

\[ 2^kT(n/2^k)+\sum_{i=0}^{k-1} n^3/4^i. \]

The sum starts at \(i=0\) (not \(1\)) and goes to \(k-1\) (not \(k\)). It is easy to get either (or both) of these wrong if you aren't careful. We should be careful to make sure we have seen the correct pattern. Too often I have seen students make a pattern out of 2 iterations. Not only is this not enough iterations to be sure of anything, the pattern they usually come up with only holds for the last iteration they did. The pattern has to match every iteration. To be safe, go one more iteration after you identify the pattern to verify that it is correct.

Continuing (with a few more steps shown to make all of the algebra as clear as possible), we get

\[ \begin{aligned} T(n)&=\ldots\\ &=2^3{\color{#0066cc}{T(n/2^3)}}+n^3/4^2+n^3/4^1+n^3/4^0\\ &=2^3{\color{#cc5500}{\left[2T(n/2^4)+(n/2^3)^3\right]}}+n^3/4^2+n^3/4^1+n^3/4^0\\ &=2^3\left[2T(n/2^4)+n^3/2^9\right]+n^3/4^2+n^3/4^1+n^3/4^0\\ &=2^4T(n/2^4)+n^3/2^6+n^3/4^2+n^3/4^1+n^3/4^0\\ &=2^4T(n/2^4)+n^3/4^3+n^3/4^2+n^3/4^1+n^3/4^0\\ &=\ldots\\ &=2^kT(n/2^k)+\sum_{i=0}^{k-1} n^3/4^i. \end{aligned} \]

Notice that this does seem to match the pattern we saw above. We can evaluate the sum to simplify it a little more:

\[ \begin{aligned} T(n)&=\ldots\\ &=2^kT(n/2^k)+\sum_{i=0}^{k-1} n^3/4^i\\ &=2^kT(n/2^k)+n^3\sum_{i=0}^{k-1} 1/4^i\\ &=2^kT(n/2^k)+n^3\sum_{i=0}^{k-1} (1/4)^i\\ &=2^kT(n/2^k)+n^3\left(\frac{1-(1/4)^k}{1-1/4}\right)\\ &=2^kT(n/2^k)+n^3(4/3)(1-(1/4)^k)\\ \end{aligned} \]

We are almost done. We just need to find a \(k\) that allows us to get rid of the recursion. Thus, we need to determine what value of \(k\) makes \(T(n/2^k)=T(1)=1\). In other words, we need \(k\) such that

\[ n/2^k=1. \]

This is equivalent to

\[ n=2^k. \]

Taking log (base 2) of both sides, we obtain

\[ \log_2 n=\log_2(2^k)=k\log_{2} 2=k. \]

So \(k=\log_2 n\). We plug in \(k\) and use the fact that \(2^{\log_2 n}=n\) along with the exponent rules to obtain

\[ \begin{aligned} T(n)&=\ldots\\ &=2^kT(n/2^k)+n^3(4/3)(1-(1/4)^k)\\ &=2^{\log_2 n}T(n/2^{\log_2 n})+n^3(4/3)(1-(1/4)^{\log_2 n})\\ &=nT(1)+n^3(4/3)\left(1-\frac{1}{(2^2)^{\log_2 n}}\right)\\ &=n\cdot 1+n^3(4/3)\left(1-\frac{1}{(2^{\log_2 n})^2}\right)\\ &=n+n^3(4/3)\left(1-\frac{1}{n^2}\right)\\ &=n+\frac{4}{3}n^3-\frac{4}{3}n\\ &=\frac{4}{3}n^3-\frac{1}{3}n. \end{aligned} \]

So we have that \(T(n)=\frac{4}{3}n^3-\frac{1}{3}n\).

Exercise 1

Use iteration to solve the recurrence

\[ H(n) = \left\{ \begin{array}{ll} 1&\mbox{when n = 1}\\ 2 H(n-1) + 1 & \mbox{otherwise} \end{array} \right. \]
\[ \begin{aligned} H(n)&=2{\color{#0066cc}{H(n-1)}} + 1\\ &=2{\color{#cc5500}{\left(2 H(n-2) + 1\right)}} + 1\\ &=2^2{\color{#0066cc}{H(n-2)}} + 2 + 1\\ &=2^2{\color{#cc5500}{\left(2 H(n-3) + 1\right)}} + 2 + 1\\ &= 2^3 H(n-3) + 2^2 + 2 + 1\\ &\vdots\\ &=2^{n-1}H(1) + 2^{n-2} + 2^{n-3}+\cdots + 2 + 1\\ &=2^{n-1} + 2^{n-2} + 2^{n-3}+\cdots + 2 + 1\\ &=2^n-1 \end{aligned} \]

Thus, \(H(n)=2^n-1\).

Example 3

Give a tight bound for the recurrence \(T(n)=T(\sqrt{n})+1\), where \(T(2)=1\).

Solution

We can see that

\[ \begin{aligned} T(n)&=T(n^{1/2})+1\\ &=T(n^{1/4})+1+1\\ &=T(n^{1/8})+1+1+1\\ &=T(n^{1/2^k})+k\\ \end{aligned} \]

If we can determine when \(n^{1/2^k}=2\), we can obtain a solution. Taking logs (base 2) on both sides, we get

\[ \log_2(n^{1/2^k})=\log_2 2. \]

We apply the power-inside-a-log rule and the fact that \(\log_2 2=1\) to get

\[ (1/2^k)\log_2 n=1. \]

Multiplying both sides by \(2^k\) and flipping it around, we get

\[ 2^k= \log_2 n. \]

Again taking logs, we get

\[ k=\log_2\log_2 n. \]

Therefore,

\[ \begin{aligned} T(n)&=T(n^{1/2^{\log_2\log_2 n}})+\log_2\log_2 n\\ &=T(2)+\log_2\log_2 n\, \, \, \mbox{(since } n^{1/2^{\log_2\log_2 n}}=2\mbox{ by the way we chose k)}\\ &=1+\log_2\log_2 n.\\ \end{aligned} \]

Therefore, \(T(n)=1+\log_2\log_2 n\).

Exercise 2

Use iteration to solve the recurrence relation for the complexity of binarySearch:

\[ T(n)=T(n/2)+1, T(1)=1. \]

Iterating a few steps, we discover:

\[ \begin{aligned} T(n)&=T(n/2)+1\\ &=T(n/4)+1+1\\ &=T(n/2^2)+2\, \, \, \, \mbox{(I think I see a pattern!)}\\ &=T(n/2^3)+1+2\\ &=T(n/2^3)+3\, \, \, \, \mbox{(I do see a pattern!)}\\ &\vdots\\ &=T(n/2^k)+k\\ \end{aligned} \]

We need to find \(k\) such that \(n/2^k=1\). As in the earlier examples, this gives \(k=\log_2 n\). Therefore, we have

\[ \begin{aligned} T(n)&=T(n/2^k)+k\\ &=T(n/2^{\log_2 n})+\log_2 n\\ &=T(1)+\log_2 n\\ &=1+\log_2 n\\ \end{aligned} \]

Therefore, \(T(n)=1+\log_2 n\).

work through it carefully, you have a strong grasp of the iteration method. If you have difficulty, keep working at it and/or get some assistance. I strongly recommend that you do your best to solve this one on your own.

Exercise 3

Solve the recurrence relation \[ T(n)=2T(n-1)+n,\qquad T(1)=1. \] In your solution, you may need the following finite-sum identity: \[ \sum_{i=1}^{k-1} i2^i=(k-2)2^k+2. \] You do not need to prove this identity for this exercise.

We solve \[ T(n)=2T(n-1)+n,\qquad T(1)=1 \] by repeated substitution. The key point is that when we substitute for \(T(n-1)\), the non-recursive term is \(n-1\), not \(n\).

\[ \begin{aligned} T(n)&=2T(n-1)+n\\ &=2\left(2T(n-2)+(n-1)\right)+n\\ &=2^2T(n-2)+2(n-1)+n\\ &=2^2\left(2T(n-3)+(n-2)\right)+2(n-1)+n\\ &=2^3T(n-3)+2^2(n-2)+2(n-1)+n. \end{aligned} \]

At this point we could try to simplify the non-recursive terms:

\[ \begin{aligned} 2^2(n-2)+2(n-1)+n &=(2^2+2+1)n-(2^2\cdot 2+2\cdot 1)\\ &=(2^3-1)n-(2^2\cdot 2+2). \end{aligned} \]

This simplification is correct, but it does not reveal anything especially useful. In fact, it hides the pattern we are trying to find. This is a good example of why it is often better to leave terms unsimplified in these problems, unless simplifying makes the pattern clearer. If we keep the expression in its unsimplified form, the effect of each substitution becomes much easier to see. To make the pattern even more visible, we can rewrite the last two terms with explicit powers and shifts:

\[ \begin{aligned} T(n)&=2^3T(n-3)+2^2(n-2)+2(n-1)+n\\ &=2^3T(n-3)+2^2(n-2)+2^1(n-1)+2^0(n-0). \end{aligned} \]

From this form, the pattern after \(k\) substitutions is

\[ \begin{aligned} T(n) &=2^kT(n-k) +2^{k-1}(n-(k-1)) +2^{k-2}(n-(k-2)) +\cdots +2^1(n-1)+2^0(n-0)\\ &=2^kT(n-k)+\sum_{i=0}^{k-1}2^i(n-i). \end{aligned} \]

Now separate the sum into two simpler sums:

\[ \begin{aligned} T(n)&=2^kT(n-k)+\sum_{i=0}^{k-1}2^i(n-i)\\ &=2^kT(n-k)+n\sum_{i=0}^{k-1}2^i-\sum_{i=0}^{k-1}i2^i\\ &=2^kT(n-k)+n(2^k-1)-\sum_{i=1}^{k-1}i2^i. \end{aligned} \]

We use the identity \[ \sum_{i=1}^{k-1} i2^i=(k-2)2^k+2. \] Therefore,

\[ \begin{aligned} T(n)&=2^kT(n-k)+n(2^k-1)-\left((k-2)2^k+2\right)\\ &=2^kT(n-k)+n2^k-n-(k-2)2^k-2\\ &=2^kT(n-k)+(n-k+2)2^k-n-2. \end{aligned} \]

To reach the base case, we need \(n-k=1\), so \(k=n-1\). Substituting \(k=n-1\), we get

\[ \begin{aligned} T(n)&=2^{n-1}T(1)+(n-(n-1)+2)2^{n-1}-n-2\\ &=2^{n-1}\cdot 1+3\cdot 2^{n-1}-n-2\\ &=4\cdot 2^{n-1}-n-2\\ &=2^{n+1}-n-2. \end{aligned} \]

Thus, \[ T(n)=2^{n+1}-n-2. \]

Reading Comprehension Questions

  1. Purpose of the Method: What is the main goal of the iteration method when solving a recurrence relation?
  2. Recursive Argument: In the recurrence \(T(n)=2T(n/2)+n^3\), why does substituting for \(T(n/2)\) produce \((n/2)^3\) rather than another \(n^3\)?
  3. Stopping the Iteration: In recurrences of the form \(T(n)=T(n/2)+1\) with \(T(1)=1\), why does the value \(k=\log_2 n\) stop the iteration?
  4. Pattern Check: Why is it risky to decide on a general pattern after only one or two substitutions?
  5. Geometric Sum: In the recurrence \(T(n)=2T(n/2)+n^3\), why does the non-recursive part become a geometric sum involving powers of \(1/4\)?
  6. Different Base Case: In the recurrence \(T(n)=T(\sqrt n)+1\) from Example 3, why do we solve \(n^{1/2^k}=2\) instead of \(n^{1/2^k}=1\)?
  7. Choosing a Method: Why is the iteration method not a good first choice for a recurrence with several different recursive terms, such as \(T(n-1)\), \(T(n-2)\), and \(T(n/3)\)?
  8. Common Algebra Error: In the recurrence \(T(n)=2T(n-1)+n\), why does substituting for \(T(n-1)\) give \(2T(n-2)+(n-1)\), not \(2T(n-2)+n\)?
  1. Answer: The goal is to repeatedly substitute the recurrence into itself until the remaining expression depends only on the base case and a non-recursive sum or pattern.
  2. Answer: The recurrence must be applied to the current input size. If the recursive term is \(T(n/2)\), then the input to that smaller problem is \(n/2\). Therefore the non-recursive term becomes \((n/2)^3\), not \(n^3\).
  3. Answer: After \(k\) substitutions the recursive part is \(T(n/2^k)\). To reach the base case, we need \(n/2^k=1\). This gives \(n=2^k\), so \(k=\log_2 n\).
  4. Answer: With too few substitutions, it is easy to simplify in a way that hides the real pattern or to guess a pattern that does not continue correctly. Doing at least three or four substitutions gives more evidence for the pattern and makes it easier to check that it matches each step of the iteration.
  5. Answer: At each level, the recursive call is multiplied by another factor of \(2\), but the new non-recursive term is evaluated on a smaller input before that outside factor is applied. For example, when expanding \(T(n/2)\), the cubic term is \((n/2)^3=n^3/8\). Since this term is also multiplied by the outside \(2\), its actual contribution is \[ 2(n/2)^3=2\cdot \frac{n^3}{8}=\frac{n^3}{4}. \] Thus the contributions are \[ n^3,\quad \frac{n^3}{4},\quad \frac{n^3}{4^2},\quad \ldots \] The factor \(2\) from the extra recursive branch partially cancels the factor \(2^3=8\) from cubing the halved input, leaving a ratio of \(1/4\) from one level to the next.
  6. Answer: The given base case is \(T(2)=1\). The iteration stops when the recursive argument reaches \(2\), so we solve \(n^{1/2^k}=2\).
  7. Answer: Iteration works best when repeated substitution creates a manageable pattern. Several different recursive terms usually produce many unrelated subproblems, making the expression branch rather than simplify into one clear sequence or sum.
  8. Answer: The recurrence \(T(m)=2T(m-1)+m\) must be applied with \(m=n-1\). Thus \(T(n-1)=2T(n-2)+(n-1)\). Keeping the correct input size is essential.

In-Class Activities

  1. Three Lines Before the Pattern: In small groups, solve the recurrence \[ T(n)=T(n-3)+2,\qquad T(1)=1. \] Use the iteration method, and expand at least four times before writing the general form.
  2. Check the Substitution: For each proposed substitution step below, determine whether it is correct. If it is incorrect, identify the error and write the corrected step.
    1. \( T(n)=3T(n/2)+n^2 =3\left(3T(n/4)+n^2\right)+n^2. \)
    2. \( T(n)=3T(n/2)+n^2 =3\left(T(n/4)+(n/2)^2\right)+n^2. \)
    3. \( T(n)=2T(n-1)+n =2\left(2T(n-2)+(n-1)\right)+n. \)
    4. \( \begin{aligned}[t] T(n)&=2T(n/2)+n^3\\ &=2\left(2T(n/4)+(n/2)^3\right)+n^3\\ &=2^2T(n/4)+n^3/8+n^3. \end{aligned} \)
  3. Keep or Combine: Expand \(T(n)=2T(n/2)+n\), \(T(1)=1\), three times. First combine the non-recursive terms immediately. Then leave them as separate terms. Discuss which version makes the pattern easier to see.
  4. Reach the Base Case: For each recursive argument below, find the value of \(k\) that makes the argument reach the base case.
    1. \(n/2^k=1\)
    2. \(n-k=1\)
    3. \(n/3^k=1\)
    4. \(n^{1/2^k}=2\)
  5. Geometric Sum Practice: Starting from \[ T(n)=2^kT(n/2^k)+n^3\sum_{i=0}^{k-1}(1/4)^i, \] complete the following steps.
    1. Substitute \(k=\log_2 n\).
    2. Use \(T(1)=1\) and \(2^{\log_2 n}=n\) to simplify the recursive term.
    3. Use \[ \sum_{i=0}^{k-1}r^i=\frac{1-r^k}{1-r} \] to evaluate the geometric sum.
    4. Simplify the final expression as far as possible.
  6. Iteration Method or Not: For each recurrence below, decide whether the iteration method looks promising. Briefly justify each answer by referring to whether repeated substitution is likely to produce a recognizable pattern.
    1. \(T(n)=T(n/2)+n^2\)
    2. \(T(n)=T(n-1)+\sqrt{n}\)
    3. \(T(n)=T(n-1)+2T(n-2)+n\)
  7. Similar but Different: Use the iteration method to solve \[ T(n)=2T(n/2)+n^2,\qquad T(1)=1. \] Show at least three substitutions before writing the pattern after \(k\) substitutions. Then determine the value of \(k\) that reaches the base case and simplify the final answer.

Homework Problems

  1. Basic Decrease Recurrence: Use iteration to solve \[ T(n)=T(n-1)+4, \qquad T(1)=3. \] Show enough substitutions to justify your pattern, state the value of \(k\) that reaches the base case, and simplify your final answer.
  2. Halving with Constant Work: Use iteration to solve \[ T(n)=T(n/2)+2, \qquad T(1)=1. \] Assume \(n\) is a power of \(2\). Then give the tight asymptotic bound.
  3. Halving with Linear Work: Use iteration to solve \[ T(n)=T(n/2)+n, \qquad T(1)=1. \] Write the non-recursive terms as a sum and simplify the sum.
  4. Two Recursive Calls with Linear Work: Use iteration to solve \[ T(n)=2T(n/2)+n, \qquad T(1)=1. \] Show why the non-recursive contribution is the same at each level.
  5. Three-Way Shrinking Recurrence: Use iteration to find a closed form for \[ T(n)=3T(n/3)+n, \qquad T(1)=1. \] Assume \(n\) is a power of \(3\).
  6. Exponential from Decrease by One: Use iteration to solve \[ T(n)=3T(n-1)+2, \qquad T(1)=1. \] Express the non-recursive terms as a geometric sum before simplifying.
  7. Square Root Recurrence: Use iteration to solve \[ T(n)=T(\sqrt n)+3, \qquad T(2)=5. \] Show how to determine the number of iterations needed to reach the base case.
  8. Find and Fix the Pattern: A student claims that the recurrence \[ T(n)=2T(n/2)+n^2, \qquad T(1)=1 \] has the pattern \[ T(n)=2^kT(n/2^k)+kn^2. \] Check the first three substitutions. Explain what is wrong with the claimed pattern, write the correct pattern, and use it to solve the recurrence.
