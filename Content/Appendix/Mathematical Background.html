Mathematical Background for Algorithm Analysis

Overview

Algorithm analysis often uses a small collection of algebra, logarithm rules, limits, and derivatives. This page reviews the facts that come up most often. Some of this material may be review, and some of it may be new. Either way, you do not need a full calculus course to follow the analysis in this text. We will use these ideas in a limited way, and you can return to this page as a reference whenever one of these tools comes up.

If limits or derivatives are new to you, it may be helpful to ask your instructor or classmates for a short primer. You do not need the full theory behind these topics here, but you should be comfortable using the basic rules listed below.

Logarithms

Logarithms appear frequently in algorithms that repeatedly divide the input, such as binary search, merge sort, and many balanced tree operations.

Logarithm Rules

For positive values \(a\), \(b\), and \(n\), and for valid logarithm bases:

  1. \(\log(ab)=\log a+\log b\)
  2. \(\log(a/b)=\log a-\log b\)
  3. \(\log(a^k)=k\log a\)
  4. \(\log_b a=\dfrac{\log_c a}{\log_c b}\)
  5. \(a^{\log b}=b^{\log a}\), when both logarithms use the same base

The change-of-base rule is especially important in algorithm analysis. It implies that changing the base of a logarithm only changes the result by a constant factor: \[ \log_b n = \frac{\log_c n}{\log_c b}. \] Since \(\log_c b\) is a constant, logarithms with different constant bases have the same general growth rate. Later, asymptotic notation will give us a formal way to express this idea. For this reason, the base of the logarithm is often not important in running-time comparisons.

Example

Since \[ \log_2 n = \frac{\log_{10} n}{\log_{10} 2}, \] the functions \(\log_2 n\) and \(\log_{10} n\) differ only by a constant factor. In algorithm analysis, this means they are usually treated as having the same type of growth.

Exponents

Exponential expressions appear in brute-force algorithms, recursive branching processes, and many counting arguments.

Exponent Rules

For positive \(a\) and \(b\):

  1. \(a^r a^s = a^{r+s}\)
  2. \(\dfrac{a^r}{a^s}=a^{r-s}\)
  3. \((a^r)^s=a^{rs}\)
  4. \((ab)^r=a^r b^r\)
  5. \(a^{-r}=\dfrac{1}{a^r}\)

Limits

Limits provide a convenient way to compare growth rates. These basic limits are often enough for the examples that arise in algorithm analysis.

Informally, a statement such as \[ \lim_{n\rightarrow\infty} f(n)=L \] means that as \(n\) gets larger and larger, the values of \(f(n)\) get closer and closer to \(L\). If the limit is \(\infty\), then \(f(n)\) does not approach a fixed number; instead, it eventually becomes larger than any fixed number.

Common Limits

  1. If \(k>0\), then \(\displaystyle \lim_{n\rightarrow\infty} n^k=\infty\).
  2. If \(k>0\), then \(\displaystyle \lim_{n\rightarrow\infty} \frac{1}{n^k}=0\).
  3. If \(a>1\), then \(\displaystyle \lim_{n\rightarrow\infty} a^n=\infty\).
  4. If \(0<a<1\), then \(\displaystyle \lim_{n\rightarrow\infty} a^n=0\).
  5. If \(b>1\), then \(\displaystyle \lim_{n\rightarrow\infty} \log_b n=\infty\).
  6. If \(k>0\), then \(\displaystyle \lim_{n\rightarrow\infty} \frac{\log n}{n^k}=0\).
  7. If \(a>1\) and \(k>0\), then \(\displaystyle \lim_{n\rightarrow\infty} \frac{n^k}{a^n}=0\).

The last two limits summarize two major growth-rate facts: logarithms grow slower than positive powers of \(n\), and polynomials grow slower than exponentials.

Common Derivatives

Derivatives are most often needed when using l'Hopital's Rule to evaluate limits. The following are the derivatives that occur most often in this setting.

Name Function Derivative
Constant rule \(c\) \(0\)
Power rule \(x^k\) \(kx^{k-1}\)
Natural log rule \(\ln x\) \(\dfrac{1}{x}\)
Logarithm rule \(\log_b x\) \(\dfrac{1}{x\ln b}\)
Natural exponential rule \(e^x\) \(e^x\)
Exponential rule \(a^x\) \(a^x\ln a\)
Sum rule \(f(x)+g(x)\) \(f'(x)+g'(x)\)
Product rule \(f(x)g(x)\) \(f'(x)g(x)+f(x)g'(x)\)
Quotient rule \(\dfrac{f(x)}{g(x)}\) \(\dfrac{f'(x)g(x)-f(x)g'(x)}{g(x)^2}\)

l'Hopital's Rule

l'Hopital's Rule is useful for comparing functions when a ratio has the form \(0/0\) or \(\infty/\infty\). In algorithm analysis, we usually use it for limits as \(x\) approaches infinity.

l'Hopital's Rule

If \(f(x)\) and \(g(x)\) are differentiable and \[ \lim_{x\rightarrow\infty} f(x) = \lim_{x\rightarrow\infty} g(x) = 0 \] or \[ \lim_{x\rightarrow\infty} f(x) = \lim_{x\rightarrow\infty} g(x) = \infty, \] then \[ \lim_{x\rightarrow\infty} \frac{f(x)}{g(x)} = \lim_{x\rightarrow\infty} \frac{f'(x)}{g'(x)}, \] provided the limit on the right exists.

Example

To compare \(\log x\) and \(x\), compute \[ \lim_{x\rightarrow\infty}\frac{\log x}{x}. \] Since both the numerator and denominator go to infinity, l'Hopital's Rule applies: \[ \lim_{x\rightarrow\infty}\frac{\log x}{x} = \lim_{x\rightarrow\infty}\frac{1/x}{1} = 0. \] Therefore, \(\log x=o(x)\), and in particular \(\log x=O(x)\).

Growth-Rate Summary

The following informal hierarchy is useful to remember. As you move from left to right, the functions grow asymptotically faster:

\[ 1 \ll \log n \ll n^c \ll a^n \ll n! \]

Here \(c>0\) is a constant and \(a>1\) is a constant. More specific examples are:

\[ 1 \ll \log n \ll \sqrt n \ll n \ll n\log n \ll n^2 \ll 2^n \ll n! \]

Quick Practice

  1. Simplify \(\log(n^3)\).
  2. Simplify \(\log(n^2/4)\).
  3. Find \(\dfrac{d}{dx}(x^3\log x)\), assuming \(\log x=\ln x\).
  4. Evaluate \(\displaystyle\lim_{n\rightarrow\infty}\frac{\log n}{n}\).
  5. Evaluate \(\displaystyle\lim_{n\rightarrow\infty}\frac{n^3}{2^n}\).
  6. Put the following in increasing asymptotic order: \(n^2\), \(\log n\), \(2^n\), \(n\log n\), \(1\).
  1. \(\log(n^3)=3\log n\).
  2. \(\log(n^2/4)=2\log n-\log 4\).
  3. Using the product rule, \(\dfrac{d}{dx}(x^3\log x)=3x^2\log x+x^2\).
  4. \(\displaystyle\lim_{n\rightarrow\infty}\frac{\log n}{n}=0\).
  5. \(\displaystyle\lim_{n\rightarrow\infty}\frac{n^3}{2^n}=0\).
  6. \(1,\log n,n\log n,n^2,2^n\).
