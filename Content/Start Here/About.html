About This Textbook

Purpose

This site is an open-access, interactive textbook for data structures, algorithms, and related courses. It is designed as an alternative or supplement to traditional textbooks by combining explanations, visual examples, interactive demos, implementation examples, and active-learning materials.

The goal is to help students understand how algorithms and data structures behave. Many ideas become clearer when students can trace examples, manipulate demos, compare implementations, and see how an algorithm or structure changes step by step.

Audience

The material is intended for several related courses.

  • An Introduction to Data Structures course might cover the Foundations and Data Structures sections in detail, along with selected searching and sorting algorithms found in the Techniques and Algorithms sections.
  • An Introduction to Algorithms course will likely use Foundations, Analysis, Techniques, Algorithms, and Problems, with selected data structure pages included as needed.

The same material can also support review, independent study, advanced topics, or supplemental assignments. Instructors can choose the sections that fit their course rather than following one fixed path through the site.

Organization

The site has eight major parts.

  • Foundations introduces concepts used throughout the site, such as abstract data types, recursion, structure diagrams, and basic analysis.
  • Analysis develops tools for comparing algorithms, including asymptotic notation, growth rates, iterative analysis, recurrence relations, and analysing recursive algorithms.
  • Data Structures studies ways of organizing data so that operations can be performed efficiently.
  • Techniques presents general algorithm design strategies such as brute force, decrease-and-conquer, divide-and-conquer, greedy algorithms, dynamic programming, and backtracking.
  • Algorithms contains specific algorithms, usually connected to the problems they solve and the techniques they use.
  • Problems describes computational tasks such as sorting, searching, shortest paths, spanning trees, and priority queue operations. Most of these pages are linked to from the relevant Algorithms pages.
  • Demos collects interactive visualizations, most of which are also embedded directly in the relevant pages.
  • More contains supplemental material such as credits, future plans, a glossary, development notes, and links to related resources.

Problems and demos are organized as reference sections. Students will usually encounter them through links from data structure, technique, or algorithm pages rather than reading them straight through.

Approach

The textbook is built around active learning. Many pages include reading comprehension questions, guided examples, activities for class discussion, and focused homework problems. Interactive demos are included where step-by-step visualization can make an idea easier to understand.

Implementation details are included when they clarify the underlying idea, but the site is not intended to teach these topics in one specific programming language. Some pages focus mainly on concepts or pseudocode. Others include implementations or partial implementations in Java, Python, and C++. Readers are expected to have completed an introductory programming course before using the implementation-focused material.

Status

This textbook is under active development. The current focus is to create and refine core content for Introduction to Algorithms and Introduction to Data Structures courses. There is almost enough content for an entire Introduction to Algorithms course (depending on the depth of the course), and about half of the necessary content for an Introduction to Data Structures course. Hopefully there will be enough for a full Introduction to Data Structures course by August, 2026.

Long-term goals include

  • Create menus for individual courses like Introduction to Algorithms and Introduction to Data Structures so the material can be more easily used in specific types of courses.
  • Add more advanced algorithm content.
  • Improve upon the content, including adding more activites and better exercises for some topics.

More detailed information about current priorities and future plans is available on the Development Plan page.

Authors

This textbook was created by Charles Cusack, with contributions from students and other collaborators. More information is available on the Credits page.

AI tools, especially ChatGPT, have been heavily used to help draft, revise, and prototype portions of this project, including explanations, examples, code, and interactive demos. AI-generated material is reviewed, edited, tested, and revised before being included. Responsibility for the final content remains with the human authors and editors.
