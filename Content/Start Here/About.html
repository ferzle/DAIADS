About This Textbook

Purpose

This site is a comprehensive, open-access, interactive textbook for data structures, algorithms, and related courses. It is designed to serve as an alternative to traditional textbooks by combining clear explanations, visual examples, interactive demos, and active-learning materials.

The goal is to make algorithms and data structures as intuitive and engaging as possible. Many concepts become easier to understand when students can trace examples, manipulate demos, compare implementations, and see how an algorithm or structure changes step by step.

Audience

The material is intended for several related contexts. An Introduction to Data Structures course might cover the Foundations and Data Structures chapters in detail, along with the various searching and sorting algorithms covered in later chapters. An Introduction to Algorithms course will likely cover Foundations, Analysis, Techniques and as many of the Algorithms as are of interest. It might also cover some of the more advanced Data Structures content.

The same material can also support selected review, independent study, or advanced topics. Instructors can choose the sections that fit their course rather than following one fixed path through the site.

Organization

The site 8 major parts.

  • Foundations introduces concepts used throughout the site, such as abstract data types, recursion, structure diagrams, and basic analysis.
  • Analysis develops the tools used to compare algorithms, including asymptotic notation, growth rates, iterative analysis, recurrence relations, and recursive analysis.
  • Data Structures studies ways of organizing data so that operations can be performed efficiently.
  • Techniques presents general algorithm design strategies such as brute force, divide-and-conquer, greedy algorithms, and dynamic programming.
  • Algorithms contains specific algorithms, usually connected to the problems they solve and the techniques they use.
  • Problems describes computational tasks such as sorting, searching, shortest paths, and spanning trees.
  • Demos collects interactive visualizations, most of which are also embedded directly in the relevant pages.
  • More contains various bits of information, including credits, future plans, a glossary, links to other books by the PI, as well as links related to Algorithms, Data Structures, and AI.

Problems and demos are organized as reference sections. Students will usually encounter them through links from data structure, technique, or algorithm pages rather than reading them straight through.

Approach

The textbook is built around active learning. Many pages include reading comprehension questions, guided examples, activities for class discussion, and focused homework problems. Interactive demos are included where step-by-step visualization can make an idea easier to understand.

Implementation details are included when they clarify the underlying idea, but the site is not intended to teach the concepts in one specific programming language. In some cases, the focus is on only pseudocode. In others, implementations or partial implementations are given in Java, Python, and C++ (since these seem to be the cost commonly used languages as of the time this was written). Readers are expected to have completed an introductory programming course before using the implementation-focused material.

Status

This textbook is under active development. The current focus is to create and refine core content for Introduction to Algorithms and Introduction to Data Structures courses. There is almost enough content for an entire Introduction to Algorithms course (depending on the depth of the course), and about half of the necessary content for an Introduction to Data Structures course. Hopefully there will be enough for a full Introduction to Data Structures course by August, 2026.

Long-term goals include

  • Create menus for individual courses like Introduction to Algorithms and Introduction to Data Structures so the material can be more easily used in specific types of courses.
  • Add more advanced algorithm content.
  • Improve upon the content, including adding more activites and better exercises for some topics.

More detailed information about current priorities and future plans is available on the Development Plan page.

Use of AI

AI tools, especially ChatGPT, have been used to help draft, revise, and prototype portions of this project, including explanations, examples, code, and interactive demos. These tools make it possible to develop and revise material more quickly.

AI-generated material is reviewed, edited, tested, and revised before being included. The responsibility for the final content remains with the human authors and editors.
