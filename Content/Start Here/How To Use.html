How to Use This Textbook

Background Assumptions

This material assumes that students have completed an introductory programming course. It does not attempt to teach a specific programming language, object-oriented programming, syntax for generics or templates, exception handling, unit testing, or basic programming constructs such as loops, conditionals, arrays, functions, and classes. Individual instructors may need to review some of these topics depending on the language used in their course and the background of their students.

The Analysis section and some of the Algorithms and Techniques sections also assume some mathematical maturity typically found in a discrete mathematics courses.

When implementation details depend heavily on a language, the text tries to emphasize the underlying data-structure or algorithmic idea first. Language-specific details can be handled in lecture, lab, or supplemental examples.

Choosing a Path Through the Site

The textbook is modular. It is not necessary for every course or reader to follow one fixed sequence through the site. Some pages are designed as core readings, while others are better used as references, review material, examples, or supplements to class activities.

Introduction to Data Structures

A data structures course will usually begin with Foundations section. The main emphasis will then be the Data Structures section, along with algorithms pages related to searching and sorting since these are the typical algorithms covered in these sorts of courses.

Introduction to Algorithms

An algorithms course will usually use more of the Analysis, Techniques, Algorithms, and Problems sections. There is approximately enough material for a 3-credit course.

Data structure pages can be consulted when they are needed to understand an algorithm. For example, priority queues are important for several graph algorithms, and disjoint sets are useful for Kruskal's algorithm.

Independent Study or Review

Readers using the site independently should start with the Foundations section, then move to the topic that matches their goal. The glossary, problem pages, and demos can be used as references whenever unfamiliar terms, problem definitions, or visual explanations are needed.

Using Individual Pages

Most pages are designed to be read actively. Rather than only skimming the explanation and then looking at the final code, readers should pause at examples, trace small inputs by hand, answer the reading questions, and use demos to check whether their mental model matches the actual behavior.

Algorithm pages usually identify the problem being solved, explain the main idea, give examples or an interactive demo, provide implementation details, analyze time and space use, and include questions, activities, or problems. Data structure pages usually emphasize the abstract operations, the representation used by an implementation, the invariants that must be maintained, and the cost of the main operations.

Problems and demos are often best used through links from the pages where they are most relevant. The separate Problems and Demos sections are also available as reference indexes.

Notes for Students

The most effective way to use this material is to work actively. For each new algorithm or data structure, try to answer four questions:

  • What problem is being solved, or what operations are being supported?
  • What information is stored, and what rules must remain true?
  • What are the main steps of the algorithm or operation?
  • What makes the method efficient or inefficient?

Reading the explanation once is usually not enough. Trace examples by hand, use the demos, answer the reading questions before revealing the answers, and practice explaining the idea without looking at the page.

Notes for Instructors

The site is designed so that instructors can assemble different paths through the material. A CS2 or data structures course may use most of the Data Structures section while treating deeper Analysis pages as optional. An algorithms course may use the Analysis, Techniques, Algorithms, and Problems sections more heavily, while assigning selected data structure pages as needed.

Activities and homework problems are included on many pages so that class time can focus on discussion, tracing, comparison, implementation choices, and student questions rather than only on lecture. Instructors should select, modify, or omit these materials based on course goals.

Because the text is modular, instructors may also assign individual pages as review material, pre-class preparation, lab support, or supplemental reading alongside another textbook.
