Asymptotic Notation

Asymptotic Notation

Asymptotic notation is used to express and compare the growth rate of functions. In our case, the functions will typically represent the running time of algorithms. We will define the asymptotic notations in terms of nonnegative functions. You will find more general definitions of these notations in other books, but they are more complicated, more difficult to understand, and harder to work with. These added difficulties are a result of the possibility of the functions involved being negative. But the main reason for our use of the notations is to express the running time of algorithms. Since the running time of an algorithm is always nonnegative, there is really no good reason to use the more cumbersome definitions. We will focus on the notations most commonly used in the analysis of algorithms, \(O\), \(\Omega\), \(\Theta\), and \(o\).

Asymptotic notation allows us to express the behavior of a function as the input approaches infinity. In other words, it is concerned about what happens to \(f(n)\) as \(n\) gets larger, and is not concerned about the value of \(f(n)\) for small values of \(n\).

We will define four of the most commonly used asymptotic notations: Big-O (\(O\)), Big-Omega (\(\Omega\)), Big-Theta (\(\Theta\)), and Little-O (\(o\)). For each notation, we will give the definition, work through examples, and discuss how it relates to the others. We will also briefly mention Little-Omega (\(\omega\)).

Big-O

Definition: Big-O

Let \(f\) be a nonnegative function.

We say that \(f(n)\) is Big-O of \(g(n)\), written as \(f(n) = O(g(n))\), iff there are constants \(c>0\) and \(n_0\geq 0\) such that \[f(n)\leq c\,g(n)\mbox{ for all }n \ge n_{0}.\] If \(f(n)=O(g(n))\), \(f(n)\) grows no faster than \(g(n)\). In other words, \(g(n)\) is an asymptotic upper bound (or just upper bound) on \(f(n)\).

Remark

The "=" in the statement "\(f(n)=O(g(n))\)" should be read and thought of as "is", not "equals." You can think of it as a one-way equals. So saying \(f(n)=O(g(n))\) is not the same thing as saying \(O(g(n))=f(n)\), for instance (with the latter statement not really making sense).

An alternative notation is to write \(f(n)\in O(g(n))\) instead of \(f(n)=O(g(n))\). It turns out that \(O(g(n))\) is actually the set of all functions that grow no faster than \(g(n)\), so the set notation is actually in some sense more correct. The "=" notation is used because it comes in handy when doing algebra. You can essentially think of these as being two different notations (\(=\) and \(\in\)) for the same thing. Similar statements are true for the other asymptotic notations.

Example 1

Prove that \(n^2+n=O(n^3)\).

Solution

Here, we have \(f(n) = n^2+n\), and \(g(n) = n^{3}\). Notice that if \(n\geq 1\), \(n\leq n^3\) and \(n^2\leq n^3\). Therefore, \[n^2+n\leq n^3+n^3=2 n^3\] Thus, \[n^2+n\leq 2 n^3 \mbox{ for all } n\geq 1.\] Thus, we have shown that \(n^2+n=O(n^3)\) by definition of Big-O, with \(n_0=1\), and \(c=2\).

The following fact is a generalization of what was used in the previous example. It is used often in proofs involving asymptotic notation.

Theorem 1

If \(a\) and \(b\) are real numbers with \(a\leq b\), then \(n^a\leq n^b\) whenever \(n\geq 1\).

Proof

We will not provide a proof, but it should be fairly clear intuitively that this is true. If you cannot see why this is true, you should work out a few examples to convince yourself.

Sometimes the easiest way to prove that \(f(n)=O(g(n))\) is to take \(c\) to be the sum of the positive coefficients of \(f(n)\), although this trick doesn't always work. We can usually easily eliminate the lower order terms with negative coefficients if we make the appropriate assumption. Let's see how to do this in the next few examples.

Example 2

Prove that \(3n^{3}- 2n^2 + 13 n -15=O(n^3)\).

Solution

First, notice that if \(n\geq 0\), then \(-2n^2-15\leq 0\), so \[3n^{3}- 2n^2 + 13 n -15\leq 3n^{3}+13n.\] Next, if \(n\geq 1\), then \(13n\leq 13n^3\). Therefore if \(n\geq 1\), \[3n^{3}+13n\leq 3n^3+13n^3=16n^3.\] Also notice that if \(n\geq 1\), then \(n\geq 0\). Thus, our first step is still valid if we assume \(n\geq 1\) since \(n\geq 1\) is a stronger condition than \(n\geq 0\). Putting this all together, if we assume \(n\geq 1\), then

\[ \begin{aligned} 3n^{3}- 2n^2 + 13 n -15 &\leq 3n^{3} +13 n \\ &\leq 3n^{3}+ 13 n^3 \\ &= 16n^3. \end{aligned} \]

Since we have shown that \(3n^{3}- 2n^2 + 13 n -15\leq 16n^3\) for all \(n\geq 1\), we have proven that \(3n^{3}- 2n^2 + 13 n -15=O(n^3)\).

We used \(n_0=1\) and \(c=16\) in our proof. It is not necessary to explicitly point this out in our proof, though. We only do so to help you see the connection between the proof and the definition of Big-O.

Example 3

Prove that \(5n^{2}- 3n +20=O(n^2)\).

Solution

If \(n\geq 1\),

\[ \begin{aligned} 5n^{2} - 3n + 20 &\leq 5n^{2} + 20 \\ &\leq 5n^2+20n^2\\ &= 25n^2. \end{aligned} \]

Since \(5n^{2} - 3n + 20 \leq 25n^2\) for all \(n\geq 1\), \(5n^{2} - 3n +20=O(n^2)\).

In this proof we used \(c=25\) and \(n_0=1\).

Question 1

Answer the following questions related to Example 3.

  1. What allowed us to eliminate the \(-3n\) term in the first step?
  2. What is the justification for the second inequality?

(a) Since we assumed that \(n\geq 1\), \(-3n\) is certainly negative. In other words, \(-3n\leq 0\). That's why in the first step we could say that \(5n^2-3n+20\leq 5n^2+20\).
(b) We used the fact that \(20\leq 20n^2\) whenever \(n\geq 1\). If either of these solutions is not clear to you, you need to brush up on your algebra.

Remark

The values of the constants used in the proofs do not need to be the best possible. For instance, if you can show that \(f(n)\leq 345\, g(n)\) for all \(n\geq 712\), then \(f(n)=O(g(n))\). It doesn't matter whether or not it is actually true that \(f(n)\leq 3\, g(n)\) for all \(n\geq 5\).

Question 2

Answer each of the following questions related to Example 3. Include a brief justification.

  1. Could we have used \(c=50\) in the proof?
  2. Could we have used \(c=2\) in the proof?
  3. Could we have used \(n_0=100\) in the proof?
  4. Could we have used \(n_0=0\) in the proof?

(a) Sure. Add the final step of \(25n^2\leq 50n^2\) to the algebra in the proof. In fact, any number above \(25\) can easily be used. Some values under 25 can also be used, but they would require a modification of the algebra used in the proof. The bottom line is that there is generally no 'right' value to use for \(c\). If you find a value that works, then it's fine.
(b) Clearly not. For this to work, we would need \(5n^2-3n+20<2n^2\) to hold as \(n\) increases towards \(\infty\). But this would imply that \(3n^2-3n+20<0\). But when \(n\geq 1\), \(3n^2\) is positive and larger than \(3n\), so \(3n^2-3n+20>0\).
(c) Sure. The proof used the fact that the inequality is true when \(n\geq 1\), so it is clearly also true if \(n\geq 100\). And the definition of Big-O does not require that we use the smallest possible value for \(n_0\).
(d) No. We would need a constant \(c\) such that \(5\cdot 0^2-3\cdot 0 + 20 = 20\leq 0= c\cdot 0^2\), which is clearly impossible.

Big-O is a notation to express the idea that one function is an upper bound for another function. The next notation allows us to express the opposite idea—that one function is a lower bound for another function.

Big-Omega

Definition: Big-Omega

Let \(f\) and \(g\) be nonnegative functions.

We say that \(f(n)\) is Big-Omega of \(g(n)\), written as \(f(n) = \Omega(g(n))\), iff there are constants \(c>0\) and \(n_0\geq 0\) such that \[c\,g(n) \leq f(n) \mbox{ for all } n \geq n_0.\] When we say \(f(n)=\Omega(g(n))\), it means that \(f(n)\) grows no slower than \(g(n)\). In other words, \(g(n)\) is an asymptotic lower bound (or just lower bound) on \(f(n)\).

Example 4

Prove that \(n^3+4\,n^2=\Omega(n^2)\).

Proof

Here, we have \(f(n) = n^3+4\,n^2\), and \(g(n) = n^2\). It is not too hard to see that if \(n\geq 1\), \[n^2\leq n^3\leq n^3+4\,n^2.\] Therefore, \[1\,n^2\leq n^3+4\,n^2 \mbox{ for all } n\geq 1\] so \(n^3+4\,n^2=\Omega(n^2)\) by definition of \(\Omega\), with \(n_0=1\), and \(c=1\).

Exercise 2

Prove that \(4n^2+n+1=\Omega(n^2)\). (This one should be really easy—follow the technique from the previous example and don't over think it.)

Since \(4n^2\leq 4n^2+n+1\) for \(n\geq 0\), \(4n^2+n+1=\Omega(n^2)\).

Question 4

What values did you use for \(n_0\) and \(c\) in your solution to Exercise 2?

\(n_0=\underline{\hspace{2.5cm}},\, \, \, c=\underline{\hspace{2.5cm}}\)

We used \(c=4\) and \(n_0=0\). You might have used \(n_0=1\) or some other positive value. As long as you chose a nonnegative value for \(n_0\), it works just fine. You could have also used any value for \(c\) larger than \(0\) and at most \(4\).

Proving that \(f(n)=\Omega(g(n))\) often requires more thought than proving that \(f(n)=O(g(n))\). Although the lower-order terms with positive coefficients can be easily dealt with, those with negative coefficients make things a bit more complicated. Often, we have to pick \(c<1\). A good strategy is to pick a value of \(c\) that you think will work, and determine which value of \(n_0\) is needed. Being able to do some algebra helps. As it turns out, we won't have to worry a whole lot about this, though. We will see a different technique to prove bounds shortly that, when it works, makes things much easier.

Big-Theta

Our third notation allows us to express the idea that two functions grow at the same rate.

Definition: Big-Theta

Let \(f\) and \(g\) be nonnegative functions.

We say that \(f(n)\) is Big-Theta of \(g(n)\), written as \(f(n) = \Theta(g(n))\), iff there are constants \(c_1>0\), \(c_2>0\), and \(n_0\geq 0\) such that \[c_1\,g(n)\leq f(n)\leq c_2\,g(n)\mbox{ for all }n \ge n_{0}.\] If \(f(n)=\Theta(g(n))\), \(f(n)\) grows at the same rate as \(g(n)\). In other words, \(g(n)\) is an asymptotically tight bound (or just tight bound) on \(f(n)\).

Example 5

Prove that \(n^2+5n+7=\Theta(n^2)\)

Proof

When \(n\geq 1\), \(n^2+5\,n+7\leq n^2+5\,n^2+7n^2\leq 13n^2.\)

When \(n\geq 0\), \(n^2\leq n^2+5\,n+7\).

Combining these, we can see that when \(n\geq 1\), \[n^2\leq n^2+5\,n+7\leq 13\,n^2,\] so \(n^2{+}5\,n{+}7=\Theta(n^2)\) by definition of \(\Theta\), with \(n_0{=}1\), \(c_1{=}1\), and \(c_2{=}13\).

Question 5

In the previous example, we combined two inequalities. One of them assumed \(n\geq 0\), the other assumed that \(n\geq 1\). In the combined inequality, we said it held if \(n\geq 1\). Is that really O.K., or did we make a subtle error?

It is O.K. Since the second inequality holds when \(n\geq 0\), it also holds when \(n\geq 1\).

In general, when you want to combine inequalities that contain two different assumptions, you simply make the more restrictive assumption. In this case, \(n\geq 1\) is more restrictive than \(n\geq 0\). In general, if you have assumptions \(n\geq a\) and \(n\geq b\), then to combine the results with these assumptions, you assume \(n\geq max(a,b)\).

Using the definition of \(\Theta\) can be inconvenient since it involves a double inequality. Luckily, the following theorem provides us with an easier approach.

Theorem 2

If \(f\) and \(g\) are nonnegative functions, then \(f(n) = \Theta(g(n))\) if and only if \(f(n) = O(g(n))\) and \(f(n) = \Omega(g(n))\).

Proof

The result follows almost immediately from the definitions. We leave the details to the reader.

This theorem implies that no new strategies are necessary for \(\Theta\) proofs since they can be split into two proofs—a Big-O proof and a \(\Omega\) proof. Let's see an example of this approach.

Example 6

Show that \(\frac{1}{2} n^{2} + 3\,n=\Theta(n^{2})\)

Proof

Notice that if \(n\geq 1\), \[\frac{1}{2} n^{2}+3\,n\leq \frac{1}{2}n^{2}+3\,n^{2}=\frac{7}{ 2}n^2,\] so \({\displaystyle \frac{1}{2}n^2 +3\,n=O(n^2)}\). Also, when \(n\geq 0\), \[ \frac{1}{2}n^2 \leq \frac{1}{2}n^2 +3n,\] so \({\displaystyle \frac{1}{2}n^2 +3\,n=\Omega(n^2)}\). Since \(\frac{1}{2}n^2 +3\,n=O(n^2)\) and \(\frac{1}{2}n^2 +3\,n=\Omega(n^2)\), then by Theorem 2, \({\displaystyle \frac{1}{2}n^2 +3\,n=\Theta(n^2)}\)

Little-o

How do you use asymptotic notation to express that \(f(n)\) grows slower than \(g(n)\)? Saying \(f(n)=O(g(n))\) doesn't work, because that only tells us that \(f(n)\) grows no faster than \(g(n)\). It might grow slower, but it also might grow at the same rate. With the notation we have, the best way to express this idea is to say that \(f(n)=O(g(n))\) and \(f(n)\neq \Theta(g(n))\). But that is awkward. Let's learn a new notation for this instead. For technical reasons that we won't get into, this notation has to be defined somewhat differently than the others.

The definition below uses limits, which you may or may not be familiar with. If you have had a calculus class, you have probably studied limits before. Otherwise, the main idea of the notation \(\displaystyle \lim_{n\rightarrow\infty} h(n)=L\) is that the values of \(h(n)\) get closer and closer to \(L\) as \(n\) gets larger and larger.

Definition: Little-O

Let \(f\) and \(g\) be nonnegative functions, with \(g\) being eventually non-zero. We say that \(f(n)\) is little-o of \(g(n)\), written \(f(n)=o(g(n))\), iff \[\lim_{n\rightarrow \infty}\dfrac{f(n)}{g(n)}=0.\] If \(f(n)=o(g(n))\), then \(f(n)\) grows asymptotically slower than \(g(n)\).

In this definition, the function \(h(n)\) from the general limit notation is the ratio \(f(n)/g(n)\), and the limit value is \(0\). Thus, \(\lim_{n\rightarrow\infty} f(n)/g(n)=0\) means that the ratio \(f(n)/g(n)\) gets closer and closer to \(0\) as \(n\) gets larger. In practical terms, \(g(n)\) grows so much faster than \(f(n)\) that \(f(n)\) becomes negligible in comparison. The function \(f(n)\) may still be getting large, but it becomes a smaller and smaller fraction of \(g(n)\). That is why \(f(n)=o(g(n))\) means that \(f(n)\) grows asymptotically slower than \(g(n)\).

Example 7

You should be able to convince yourself that \(3n+2=o(n^2)\), but \(3n+2\neq o(n)\). Similarly, \(n^2+n + 4=o(n^3)\) and \(n^2+n + 4=o(n^4)\), but \(n^2+n + 4\neq o(n^2)\) and \(n^2+n + 4\neq o(n)\).

If you are not comfortable with limits you can still convince yourself of these statements by thinking of the informal definition. For instance, \(n^2+n + 4\) grows slower than \(n^3\) so \(n^2+n + 4=o(n^3)\). On the other hand, \(n^2+n + 4\) grows at the same rate (so not slower than) \(n^2\), so \(n^2+n + 4\neq o(n^2)\).

Question 6

Why do we require that \(g(n)\) be eventually non-zero in the definition of little-o?

\(g(n)\) appears in the denominator of a fraction. If at some point it does not become (and remain) non-zero, the limit in the definition will be undefined. If you never took a calculus course and are not that familiar with limits, do not worry a whole lot about this subtle point.

Little-omega (\(\omega\)) is the corresponding notation for growing asymptotically faster. It can be defined similarly to little-o, but the value of the limit is \(\infty\) instead of \(0\): if \[ \lim_{n\rightarrow\infty}\frac{f(n)}{g(n)}=\infty, \] then \(f(n)=\omega(g(n))\). In other words, \(f(n)\) grows so much faster than \(g(n)\) that \(g(n)\) becomes negligible in comparison. Little-omega is useful, but it does not come up as often as \(O\), \(\Omega\), \(\Theta\), and \(o\) in our analysis examples.

Question 7

Big-O notation is analogous to \(\leq\) in certain ways. What are the similar analogies for \(\Omega\), \(\Theta\), \(o\), and \(\omega\)?

\(O\) is like \(\leq\), \(\Omega\) is like \(\geq\), \(\Theta\) is like \(=\), \(o\) is like \(<\), and \(\omega\) is like \(>\). These analogies are useful for intuition, but they should not be treated as formal definitions.

Using Asymptotic Notation

Now that we have introduced the main asymptotic notations, it is useful to pause and compare what each one tells us. Some notations give only one-sided bounds, while others describe a more precise relationship between two functions. The following examples and questions focus on these distinctions.

Remark

  • It is important to remember that an \(O\)-bound is only an upper bound, and that it may or may not be a tight bound. So if \(f(n)=O(n^{2})\), it is possible that \(f(n)=3n^2+4\), \(f(n)=\log n\), or any other function that grows no faster than \(n^2\). But we also know that \(f(n)\neq n^3\) or any other function that grows faster than \(n^2\).
  • Conversely, a \(\Omega\)-bound is only a lower bound. Thus, if \(f(n)=\Omega(n\log n)\), it might be the case that \(f(n)=2^n\), but we know that \(f(n)\neq 3n\), for instance.

  • Unlike the others, \(\Theta\)-bounds are precise. So, if \(f(n)=\Theta(n^2)\), then \(f\) has quadratic growth: it is bounded above and below by constant multiples of \(n^2\) for sufficiently large \(n\). It might be that \(f(n)=3n^2\), \(2n^2-43n-4\), or even \(n^2+n\log n\).

  • Unlike \(O\), little-o describes a strictly slower growth rate. So, if \(f(n)=o(n^2)\), then \(f\) grows slower than \(n^2\), not merely no faster than \(n^2\). For example, \(n\log n=o(n^2)\) and \(n=o(n^2)\), but \(3n^2+7\neq o(n^2)\), since it grows at the same rate as \(n^2\), not slower.

Question 8

Answer the following questions about the asymptotic notations.

  1. If \(f(n)=\Theta(g(n))\), is it possible that \(f(n)=o(g(n))\)? Explain.
  2. If \(f(n)=O(g(n))\), is it possible that \(f(n)=o(g(n))\)? Explain.
  3. If \(f(n)=O(g(n))\), is it certain that \(f(n)=o(g(n))\)? Explain.
  4. If \(f(n)=o(g(n))\), is it possible that \(f(n)=O(g(n))\)? Explain.

(a) No. If \(f(n)=\Theta(g(n))\), \(f\) and \(g\) grow at the same rate. But \(f(n)=o(g(n))\) expresses the idea that \(f\) grows slower than \(g\). It is impossible for \(f\) to grow at the same rate as \(g\) and slower than \(g\).
(b) Yes! If \(f\) grows no faster than \(g\), then it is possible that it grows slower. For instance, \(n=O(n^2)\) and \(n=o(n^2)\) are both true.
(c) No. If \(f\) and \(g\) grow at the same rate, then \(f(n)=O(g(n))\), but \(f(n)\neq o(g(n))\). For instance, \(3n=O(n)\), but \(3n\neq o(n)\).
(d) Yes. In fact, it is guaranteed! If \(f\) grows slower than \(g\), then \(f\) grows no faster than \(g\).

Students were asked to prove the following:

Let \(a_0,\ldots, a_k\in \mathbb{R}\), where \(a_k>0\). Prove that \(a_kn^k+a_{k-1}n^{k-1}+\cdots+a_1n+a_0=O(n^k)\).

Evaluate how each student did. If they are incorrect, explain what they did wrong.

  1. We can first eliminate all of the constants since they become irrelevant as \(n\) grows large enough. This leaves us with \(n^k+n^{k-1}+\cdots+n=O(n^k)\). Next we can eliminate all terms growing slower than \(n^k\), since they also become irrelevant as \(n\) grows. This leaves us with \(n^k=O(n^k)\), and since they are the same, they are effectively theta of each other, and by definition, anything that is theta of something is also omega and \(O\), so we can correctly say that \(n^k=O(n^k)\), thus proving that \(a_kn^k+a_{k-1}n^{k-1}+\cdots+a_1n+a_0=O(n^k)\).
  2. Let \(c=\displaystyle\sum_{i=0}^k |a_i|\). Then if \(n\geq 1\),
    \[ \begin{aligned} a_kn^k+a_{k-1}n^{k-1}+\cdots+a_1n+a_0&\leq |a_k|n^k+|a_{k-1}|n^{k-1}+\cdots+|a_1|n+|a_0|\\ &\leq |a_k|n^k+|a_{k-1}|n^k+\cdots+|a_1|n^k+|a_0|n^k\\ &\leq \displaystyle\sum_{i=0}^k |a_i|n^k=cn^k. \end{aligned} \]
    Therefore, \(a_kn^k+a_{k-1}n^{k-1}+\cdots+a_1n+a_0=O(n^k)\).

    1. This student misunderstands the concept behind 'ignoring the constants.' We can ignore the constants after we know that \(f(n)=O(g(n))\). We can't ignore them in order to prove it.
    2. The phrase 'become irrelevant' (used twice) is not precise. We have developed mathematical notation for a reason—it allows us to make statements like these precise. It's kind of like saying that a certain car costs 'a lot'. What is 'a lot'? Although $30,000 might be a lot for most of us, people with a lot more money than I have might not think that $500,000 is a lot.
    3. The phrase 'This leaves us with \(n^k+n^{k-1}+\cdots+n=O(n^k)\)' is odd. What precisely do they mean? That this is true or that this is what we need to prove now? In either case, it is incorrect. Similarly for the second time they use the phrase 'This leaves us with'.
    4. The second half of the proof is unnecessarily convoluted. They essentially are claiming that their proof has boiled down to showing that \(n^k=O(n^k)\). To prove this, they use an incredibly drawn out, yet vague, explanation that is in a single unnecessarily long sentence. Why are they even bringing \(\Theta\) and \(\Omega\) into this proof? Why don't they just say something like 'since \(n^k\leq 1n^k\) for all \(n\geq 1\), \(n^k=O(n^k)\)'? I believe the answer is obvious: they don't really understand what they are doing here. They clearly have a vague understanding of the notation, but they don't understand the formal definition.

    The bottom line is that this student understands that the statement they needed to prove is correct, and they have a vague sense of why it is true, but they did not have a clear understanding of how to use the definition of Big-O to prove it. The most important thing to take away from this example is this: Be precise, use the notation and definitions you have learned, and if your proofs look a lot different than those in the book, you might question whether or not you are on the right track.

Exercise 3

Assume that \(f(n)=O(n^2)\) and \(g(n)=O(n^3)\). What can you say about the relative growth rates of \(f(n)\) and \(g(n)\)? In particular, does \(g(n)\) grow faster than \(f(n)\)?

We cannot say anything about the relative growth rates of \(f(n)\) and \(g(n)\) because we are only given upper bounds for each. It is possible that \(f(n)=n^2\) and \(g(n)=n\), so that \(f(n)\) grows faster, or vice-versa. They could also both be \(n\).

Keep in mind that asymptotic notation only allows you to compare the asymptotic behavior of functions. Except for \(\Theta\)-notation, it only provides a bound on the growth rate. For instance, knowing that \(f(n)=O(g(n))\) only tells you that \(f(n)\) grows no faster than \(g(n)\). It is possible that \(f(n)\) grows a lot slower than \(g(n)\).

Common Growth Rates

To use asymptotic notation well, we also need to compare common growth rates. We will study this idea more carefully later, but the following ordering is useful for the examples and exercises on this page.

We will write \(f(n)\prec g(n)\) to mean that \(f(n)=o(g(n))\). In other words, \(f(n)\prec g(n)\) means that \(f(n)\) grows asymptotically slower than \(g(n)\).

Using this notation, a useful ordering of common growth rates is:

\[ 1 \prec \log n \prec n \prec n\log n \prec n^2 \prec n^3 \prec 2^n \prec 3^n \prec n!. \]

This ordering is asymptotic. It does not mean that the functions are ordered this way for every small value of \(n\). It means that, eventually, each function in the list grows slower than every function to its right.

Constant factors and lower-order terms do not change the asymptotic growth rate. For example, \(100n\), \(3n+20\), and \(n/5\) are all \(\Theta(n)\). Similarly, \(4n^2+7n+9\) is \(\Theta(n^2)\).

Remark

The base of the logarithm does not matter for asymptotic notation, as long as the base is a constant greater than \(1\). For example, \(\log_2 n\), \(\log_{10} n\), and \(\ln n\) differ only by constant factors, so they are all \(\Theta(\log n)\).

Reading Comprehension Questions

  1. Purpose of Asymptotic Notation: What does asymptotic notation describe, and why is it useful when analyzing algorithms?
  2. Big-O Definition: In the definition of \(f(n)=O(g(n))\), what roles do the constants \(c\) and \(n_0\) play?
  3. Upper Bound versus Tight Bound: If \(f(n)=O(g(n))\), does that mean \(f(n)\) and \(g(n)\) grow at the same rate? Explain.
  4. Big-Omega Definition: What does it mean to say that \(f(n)=\Omega(g(n))\)? How is this different from saying \(f(n)=O(g(n))\)?
  5. Big-Theta Definition: Explain why \(f(n)=\Theta(g(n))\) can be viewed as combining both a Big-O statement and a Big-Omega statement.
  6. Choosing Constants: In a Big-O or Big-Omega proof, do the constants have to be the best possible constants? Explain.
  7. Little-o Meaning: What does \(f(n)=o(g(n))\) mean in terms of the ratio \(f(n)/g(n)\)? What does it mean informally?
  8. Comparing Notations: Match each notation with its rough inequality analogy: \(O\), \(\Omega\), \(\Theta\), \(o\), and \(\omega\).
  1. Answer: Asymptotic notation describes the long-term growth rate of a function as the input size grows. In algorithm analysis, it helps us describe how running time or memory use grows without focusing on exact constants or small input sizes.
  2. Answer: The constant \(c\) is the constant multiplier on \(g(n)\), and \(n_0\) is the point after which the inequality must hold. For Big-O, we need \(f(n)\leq c\,g(n)\) for every \(n\geq n_0\).
  3. Answer: No. A Big-O bound is only an upper bound. If \(f(n)=O(g(n))\), then \(f(n)\) grows no faster than \(g(n)\), but it might grow strictly slower. For example, \(n=O(n^2)\).
  4. Answer: Saying \(f(n)=\Omega(g(n))\) means that \(f(n)\) grows no slower than \(g(n)\), or equivalently that \(g(n)\) is an asymptotic lower bound for \(f(n)\). Big-O gives an upper bound, while Big-Omega gives a lower bound.
  5. Answer: A \(\Theta\)-bound gives both an upper and lower bound. By Theorem 2, \(f(n)=\Theta(g(n))\) if and only if \(f(n)=O(g(n))\) and \(f(n)=\Omega(g(n))\).
  6. Answer: No. The constants do not have to be the best possible. It is enough to find constants that make the required inequality true for all sufficiently large \(n\).
  7. Answer: The statement \(f(n)=o(g(n))\) means \[ \lim_{n\rightarrow\infty}\frac{f(n)}{g(n)}=0. \] Informally, \(f(n)\) grows asymptotically slower than \(g(n)\). The function \(f(n)\) becomes a smaller and smaller fraction of \(g(n)\).
  8. Answer: \(O\) is like \(\leq\), \(\Omega\) is like \(\geq\), \(\Theta\) is like \(=\), \(o\) is like \(<\), and \(\omega\) is like \(>\). These are only analogies, not formal definitions.
