# Programming Exercises v0 Archive

This directory preserves the original production programming-exercise
starters and their earlier, weaker test suites as they existed before the v2
test expansion was promoted. The snapshot was created on 2026-09-28 from
`Content/Code/`.

## Contents

- `Content/Code/` mirrors the production starter-code hierarchy.
- The snapshot contains 32 assignments and 95 self-contained source files:
  32 Java, 32 C++, and 31 Python files.
- `map-library-bst` intentionally has no Python version.
- The implementation exercises remain unfinished; this archive does not
  contain instructor solutions.

## Purpose

Keep this tree as a historical baseline for comparing the original tests with
the expanded v2 tests in
`internal/programming-exercises-v2/Content/Code/`. Relative source paths are
the same in v0, v2, and the production `Content/Code/` tree.

This archive is not the source for public downloads and should not be edited
to track later production changes. New student-facing updates belong in the
appropriate candidate tree and should be deliberately promoted to
`Content/Code/` after verification.

Instructor solutions are stored separately under
`internal/programming-exercise-solutions/Content/Code/` and must never be
copied into this archive or the production starter tree.
